# libyara in Tidy

`libyara/` is libyara 4.5.4, the library of [YARA](https://virustotal.github.io/yara/) by The YARA
Authors. It was taken from the yara-python 4.5.4 source release on PyPI
(`yara_python-4.5.4.tar.gz`, SHA-256 `4c682170f3d5cb3a73aa1bd0dc9ab1c0957437b937b7a83ff6d7ffd366415b9c`),
which carries libyara's source under `yara/libyara`.

No libyara file was changed. Parts Tidy doesn't build were left out: the command-line tools, the
`cuckoo`, `magic`, `demo` and `pb_tests` modules, the PE Authenticode parser (it needs OpenSSL),
and the process-memory scanners other than `proc/none.c` (Tidy only scans files).

Tidy's own files here: `tidy_yara.c`, `tidy_hash_module.c`, `libyara/include/tidy_yara.h` and
`libyara/include/module.modulemap`.
